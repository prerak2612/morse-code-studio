# Architecture

`compiler.js` contains the arithmetic compiler and Morse source conversion. `src/compiler` contains the message compiler used by Signal Lab. Both use the same Morse symbol table. `script.js` wires the interface to these pipelines and the playback modules in `src/codegen`. The browser loads the modules as classic scripts. Node uses CommonJS for tests.

## Pipeline

| Stage | Input | Output |
| --- | --- | --- |
| Signal | Text or dot/dash groups | Plain source and its Morse representation |
| Lexer | Plain source | Tokens with lexemes and 1-based positions |
| Parser | Tokens | Abstract syntax tree for assignments, prints, and expressions |
| Semantic analysis | Syntax tree | Symbol table assigning names to numeric slots |
| Code generation | Syntax tree and symbol table | Stack instructions |
| Optimization | Stack instructions | Equivalent instructions with constant arithmetic folded when enabled |
| Runtime | Generated instructions | Values emitted by `PRINT` and any runtime diagnostic |

The parser uses precedence climbing for expressions. Semantic analysis processes statements in program order. A declaration's initializer can reference previously declared names. Duplicate declarations, forward references, and assignments to undeclared names are errors.

## Grammar

```ebnf
program    = { end }, statement, { end, { end }, statement }, { end }, EOF ;
statement  = "LET", identifier, "=", expression
           | "SET", identifier, "=", expression
           | "PRINT", expression ;
expression = term, { ("+" | "-"), term } ;
term       = unary, { ("*" | "/"), unary } ;
unary      = ("+" | "-"), unary | primary ;
primary    = number | identifier | "(", expression, ")" ;
end        = NEWLINE | ";" ;
```

Identifiers start with an ASCII letter or underscore and may contain digits after the first character. Commands are reserved words. A number is a sequence of digits, optionally followed by a decimal point and more digits. Values use JavaScript's finite floating-point number representation. Binary operators with equal precedence associate left to right.

## Bytecode

| Instruction | Stack effect |
| --- | --- |
| `PUSH value` | Push a numeric constant |
| `LOAD slot` | Push the value stored in a variable slot |
| `STORE slot` | Pop a value and store it in a slot |
| `ADD`, `SUB`, `MUL`, `DIV` | Pop right and left operands and push the result |
| `NEG` | Pop and negate the top value, then push it |
| `PRINT` | Pop and emit the top value |

Constant folding replaces arithmetic instructions and adjacent constant operands with a single `PUSH` when the result is finite. Operations that would divide by zero or overflow stay in the generated bytecode so the VM reports the fault at its source location and preserves earlier output. The VM only dispatches the instructions emitted by code generation.

## Morse

Signal translation shares the International Morse lookup with the signal lab. Source mode also keeps statement newlines and adds `...-.-` for multiplication. Playback derives dit, dah, and gap durations from a common unit of `1200 / WPM` milliseconds. Its dot, dash, intra-character, inter-character, and word durations are respectively 1, 3, 1, 3, and 7 units.

The Signal Lab lexes a message into positioned tokens, parses them into words and characters, validates known symbols, and lowers the result to timing instructions. Those same instructions drive dot/dash text emission and the timed audio and light outputs. See [Semantic analysis and IR](docs/SEMANTIC_AND_IR.md) for the signal instruction format.
