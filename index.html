Language guide

    

      
Pulsefield programs use case-insensitive commands and variable names. End each statement with a newline or semicolon.

      

        
LET NAME = expression
Declare a variable and give it a value.

        
SET NAME = expression
Assign a new value to a declared variable.

        
PRINT expression
Write the result to the program output.

      

      
Expressions support numbers, variables, parentheses, unary signs, and + - * /. Multiplication and division bind more tightly than addition and subtraction.

      
In Morse mode, separate characters with spaces and words with /. Keep newlines between statements. The compiler reserves ...-.- for *. Toggle between Text and Morse to translate your program.
